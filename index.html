Deine Listen auf diesem Gerät

    Nur in diesem Browser gemerkt. Der Bearbeiten-Link bleibt dein einziger Zugang.

      Liste anlegen

      Du bekommst zwei Links: einen geheimen zum Bearbeiten, einen zum Weitergeben.

      Einstellungen Erscheinungsbild, Schlüssel, Liste löschen

      Erscheinungsbild

      Gilt für diesen Browser, nicht für die Liste.

      Zwischenspeicher

      Entfernt alles, was diese Anwendung in diesem Browser ablegt: Sprache, Erscheinungsbild, KI-Schlüssel, die gemerkten Listen und im Vorschaumodus die lokal gehaltenen Listen. Deine Liste auf dem Server und deine Links bleiben unberührt.

      Sprache und KI-Strukturierung

      Ohne Schlüssel zerlegt der Browser den gesprochenen Text selbst. Mit einem eigenen Gemini-Schlüssel übernimmt das die KI, dann verlässt der gesprochene Text dein Gerät.

      Bleibt ausschließlich in diesem Browser. Er wird weder auf den Server übertragen noch in die Liste aufgenommen und gilt daher nicht für deine Freunde.

      Liste löschen

      Die Liste wird unwiderruflich vom Server entfernt. Beide Links laufen danach ins Leere.
